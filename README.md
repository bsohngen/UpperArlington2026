# UpperArlington2026
Upper Arlington House Value Analysis
This repository provides data and analysis for the Upper Arlington House Value Analysis I developed in October 2026. All questions should be directed to Brent Sohngen (sohngenb@gmail.com)
The original data steps to download the data from the Franklin County Auditor site as well as the general Franklin County regression and Upper Arlington regression analysis were done by Sohngen in SAS
The code for the difference-in-differences analysis were initially generated by ChatGPT and implemented in Python and STATA on my computer.
